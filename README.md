# Portafolio de Cristian Rivera

Sitio personal que presenta algunos proyectos web y mi experiencia como estudiante de Ingeniería Informática en Duoc UC.

## Archivos

- `index.html`: contenido del portafolio.
- `style.css`: estilos, colores y adaptación para pantallas pequeñas.

El sitio se publica desde la rama `main` con GitHub Pages. Para verlo localmente, abre `index.html` en un navegador.
